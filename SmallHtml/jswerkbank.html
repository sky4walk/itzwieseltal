      Kurzreferenz der Werkbank
      
console.log(a, b, …) Ausgabe · console.warn / console.error / console.info farbig · console.table(array) als Tabelle · console.count(), console.time()/timeEnd(), console.assert(bed, text), console.group()/groupEnd(), console.clear()

      
let name = await eingabe("Wie heißt du?") liest eine Eingabe aus der Konsole (immer Text – Zahlen mit Number(...) umwandeln).

      
await warte(500) pausiert 500 ms. await funktioniert direkt im Programm.

      
Werkbank-Interpreter: Die Seite bringt ihren eigenen JavaScript-Interpreter mit (Tokenizer, Parser, Auswerter) und nutzt kein eval. Er versteht modernes JavaScript: let/const, Funktionen und Pfeilfunktionen, Closures, Klassen mit extends, Gettern, statischen und privaten (#) Feldern, Zerlegung, Spread, Template-Texte, Generatoren, async/await, Promises, try/catch, Marken (break aussen). Nicht unterstützt: import/export, with, async-Generatoren, for await, static { }-Blöcke. Der Code läuft im „strict mode“ und hat keinen Zugriff auf die Seite (kein document).

      
Debugger: ⤵ Schritt startet das Programm angehalten bzw. führt die nächste Anweisung aus, ↷ Drüber führt Funktionsaufrufe am Stück aus, ⤴ Raus läuft bis zum Ende der aktuellen Funktion, ⏵ Weiter bis zum nächsten Haltepunkt. Haltepunkte setzt du mit einem Klick auf die Zeilennummer, im Code geht auch debugger;. Rechts siehst du Aufrufstapel und Variablen – geänderte Werte sind markiert. Die Zeitlupe führt das Programm sichtbar Zeile für Zeile aus. Rückruffunktionen in map, filter, sort usw. kannst du ebenfalls Schritt für Schritt verfolgen (bei „Bibliothek: Browser“ laufen sie am Stück).

      
📚 Bibliothek: Math, JSON, Map, Set, Object, parseInt/parseFloat sowie alle Methoden von Arrays (map, sort, …), Texten (split, toUpperCase, …) und Zahlen (toFixed, …) sind selbst in JavaScript geschrieben. Über „📚 Bibliothek“ kannst du den Quelltext lesen, mit „In Bibliothek springen“ der Debugger hineinlaufen. Vom Browser kommen nur Grundbausteine (Bits einer Kommazahl, Zeichencodes, reguläre Ausdrücke) sowie Promise, Date, RegExp, Symbol, BigInt und die Fehlerklassen. Die Werkbank-Bibliothek rechnet z. B. Math.sin oder Math.exp doppelt genau und ist damit oft auf die letzte Stelle genauer als der Browser – aber deutlich langsamer. Für rechenintensive Programme „Bibliothek: Browser (schnell)“ wählen.

      
Browser (Vergleich): führt denselben Code mit der JavaScript-Engine des Browsers in einem Web-Worker aus – praktisch zum Gegenprüfen.
